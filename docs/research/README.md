# Research & legal notes

Dated record of the external research behind decisions in this project — tax
treatment, instrument availability, regulatory constraints, and portfolio
structure findings. Kept in the repo so the reasoning survives the chat window
and can be re-checked later.

## Conventions

- **One file per topic**, named `YYYY-MM-DD-topic.md` using the date the research
  was done.
- Every file starts with a **Date** and **Status** line. Status is one of:
  `verified` (primary or multiple independent sources agree), `unverified`
  (sources conflict or nothing primary found), `superseded` (a later entry
  replaces it — link to the replacement).
- **Sources are listed with links.** A claim without a source is marked as such.
- **Corrections are recorded, not silently edited.** If a later entry reverses an
  earlier one, both stay, and the earlier is marked `superseded`.
- **No personal figures.** Weights and percentages only — no balances, account
  numbers, or holdings quantities. This repo is not the right place for them.
- Tax law changes. Anything older than a tax year should be re-checked before it
  is relied on.
